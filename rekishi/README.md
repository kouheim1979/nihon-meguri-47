# 偉人のふるさと

日本の歴史上の人物81人の「生まれた都道府県」を答える、スマートフォン対応の4択クイズです。

公開先: https://kouheim1979.github.io/nihon-meguri-47/rekishi/

既存の日本めぐりアプリと独立した `rekishi/` です。親アプリの HTML / JS / CSS / データ / 保存キーは変更しません。ビルド不要で、GitHub Pages の既存の main / root 公開に含まれます。

## 遊び方と機能

- 5・10・20問を選択（ジャンルの人数が少ない場合はその人数まで）。問題と選択肢はランダム、同じ旅の中で人物は重複しません。
- 武将・天下人8人、幕末・維新13人、文学・芸術32人、学問・発明28人。
- ふつう：全国から誤答を抽選。むずかしい：混同しやすい活動地や同じ地方の都道府県を優先します。
- 2択ヒント、正誤と短い解説、各問の出典リンク、結果の振り返り、結果コピー。
- 人物図鑑（名前・かな・都道府県・手がかりで検索）、人物スタンプ帳、誤答・ヒント使用の人物だけを復習。
- 時間制限なし。キーボードの1〜4でも回答できます。タップ対象には `touch-action: manipulation` を指定し、ピンチ拡大は禁止していません。

## 採点・記録

ヒントなし正解は100点、ヒント使用の正解は50点、誤答は0点。1回の結果は各問の点数の平均を四捨五入した100点満点です。自己ベストは全ジャンル・全難度共通です。

ヒントなし正解で習得スタンプを付け、復習リストから外します。誤答・ヒント使用で習得を外し、復習リストに入れます。単なる正答率にはヒント使用の正解も含みます。途中で終了しても回答済みの人物の記録は残りますが、進行中の出題そのものの復元は行いません。

保存はこのページを開いたブラウザの localStorage `ijin-birthplace-v1` のみ。ログイン・広告・解析・外部API・利用記録のサーバー送信はありません。出典リンクを開いた場合は、その外部サイトに移動します。保存が拒否された環境でも、その場でクイズを続けられます。リセットはこのクイズ専用のキーだけを更新します。

## 史実と出典の扱い

本作の「出身地」は、出生地を現在の都道府県に対応させたものです。育った場所、領地、主な活動地、亡くなった場所とは区別します。古い地名を現在の都道府県に直した解答であり、その時代にその県が存在したという意味ではありません。

国立国会図書館「近代日本人の肖像」、自治体、博物館、公式観光サイト、ジャパンサーチの解説を参照しています。石川県・広島県・和歌山県は各12人を収録し、おまかせ出題ではこの3県を多めに抽選します。人物ごとの根拠URLは `data.js` の `source` フィールドで保持し、回答後と図鑑に表示します。出典確認日：2026-09-23。解説は本作向けに短く書き直したものです。

注意例：伊達政宗＝山形県、福沢諭吉＝大阪府、徳川慶喜＝東京都。織田信長の生誕の城は伝承として表現しています。出生地が都道府県単位でも確定しにくい人物は無理に収録していません。肖像画像や史料の転載はありません。背景はオリジナルの模式的な風景で、特定の城や史跡を再現したものではありません。

## 開発・テスト

依存パッケージやビルドは不要です。`index.html` を静的配信してください。

```sh
python -m http.server 8000
# http://localhost:8000/rekishi/
node --test rekishi/test.cjs
```

`test.cjs` は Node.js 組み込みのテストランナーを使用。データ、人数、選択肢の一意性、正答の保証、難度、出題上限、復習、保存データの検証を14テストで確認します。独立した GitHub Actions ワークフロー `.github/workflows/verify-rekishi.yml` でも実行します。親アプリのワークフローは変更しません。

`browser_test.py` は Playwright Python と Chromium がある環境で実行する、ネットワークを使わないブラウザテストです。実際のHTML・CSS・JSを読み込み、localStorageだけをテスト用の実装に置き換えます。採点・連打防止・ヒント・復習・図鑑検索・リセット・保存拒否・320/390/768/1280pxでの横はみ出し等を46項目確認します。実機iOS Safariや本番HTTP配信を検証するものではありません。

```sh
python rekishi/browser_test.py
# Chromium を自動検出できない場合: CHROMIUM_PATH=/path/to/chromium python rekishi/browser_test.py
```

ファイル構成：`index.html`（枠組み）、`style.css`（表示）、`data.js`（人物と出典）、`core.js`（抽選・記録）、`app.js`（画面・操作）。
