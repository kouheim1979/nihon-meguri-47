# 日本めぐり47

47都道府県をめぐる、日本語の4択クイズアプリです。

[アプリを開く](https://nihon-meguri-47.hhkouheim.chatgpt.site)

## 内容

- 全47都道府県・218問を収録
- 県庁所在地、名所、ご当地グルメ、伝統工芸、面積の5ジャンル
- おまかせモードでは5ジャンルから2問ずつ出題
- 1回10問、時間制限なし
- ふりがなの表示切り替え
- 正解・不正解の表示と解説
- 間違えた問題だけの復習
- スマートフォン、タッチ操作、キーボードの1〜4に対応

## ファイル

| ファイル | 内容 |
| --- | --- |
| index.html | アプリの入口 |
| style.css | デザインとレスポンシブ表示 |
| app.js | 画面、採点、復習の処理 |
| data.js | 都道府県・問題データ、出典、出題処理 |

## ローカルで開く

JavaScriptのモジュールを使うため、HTTPサーバーで配信してください。Pythonがある環境なら、フォルダー内で次を実行できます。

```sh
python3 -m http.server 8000
```

ブラウザーで http://localhost:8000/ を開きます。外部ライブラリやビルド処理は不要です。

## データについて

面積は国土地理院の2026年4月1日時点の資料に基づきます。境界未定地域を含む参考値も含めた順位を使用しています。県庁所在地はJ-LIS、伝統工芸は伝統的工芸品産業振興協会、郷土料理は農林水産省、観光地は日本政府観光局などの公開資料を参考にしています。出典のリンクはアプリ内とdata.jsに記載しています。

地図は都道府県の位置と形を簡略化したタイル図です。成績は画面を開いている間だけ保持されます。
